# 🛡️ SIGNALSAFE

## AI-Powered Crowd Safety & Emergency Management System

SIGNALSAFE is a web-based crowd safety and emergency management system.

## Features

- User Dashboard
- Admin Dashboard
- Crowd Monitoring
- Risk Map
- CCTV + AI People Detection
- GPS Location
- Emergency SOS
- Admin Safety Alerts
- Safe Route
- Event Analytics

## Technologies

- Python
- FastAPI
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript

## How to Run

### Backend

Open the terminal inside the backend folder.

Run:

python -m uvicorn main:app --reload

Backend URL:

http://127.0.0.1:8000

API Documentation:

http://127.0.0.1:8000/docs

### User Dashboard

Open:

frontend/index.html

Use VS Code Live Server.

### Admin Dashboard

Open:

admin/index.html

Use VS Code Live Server.
