# 🛡️ SIGNALSAFE

## AI-Powered Crowd Safety & Emergency Management System

SIGNALSAFE is a web-based crowd safety and emergency management system.

## Features

- 👤 User Dashboard
- 👨‍💼 Admin Dashboard
- 👥 Crowd Monitoring
- 🗺️ Risk Map
- 📹 CCTV + AI People Detection
- 📍 GPS Location
- 🚨 Emergency SOS
- 📢 Admin Safety Alerts
- 🚶 Safe Route
- 📊 Event Analytics

## Technologies

- Python
- FastAPI
- SQLAlchemy
- SQLite
- HTML
- CSS
- JavaScript
